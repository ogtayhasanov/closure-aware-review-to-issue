1257: \paragraph{Raw metadata localizes the mechanism.}
1258: The subsequent human audit of the raw-metadata arm also yields 34/36
1259: status-correct responses (94.4\%). At the aggregate level it therefore matches
1260: the structured arm and is dramatically above binary state. We do not claim a
1261: status-accuracy increment from the four-class taxonomy over raw metadata on
1262: these 36 cases. Instead, the human result localizes the dominant intervention:
1263: preserving closure-reason evidence prevents the information loss caused by a
1264: binary open/closed representation. The taxonomy's additional contribution is
1265: to convert heterogeneous Bugzilla, Trac, and GitHub signals into a deterministic,
1266: inspectable Level~1 decision and explicit response action. Because the
1267: raw-metadata human arm was added post hoc after the structured/binary audit,
1268: we report its 34/36 rate descriptively rather than attach confirmatory paired
1269: inference to the structured-versus-raw contrast.
1270: 
1271: \paragraph{Action realization distinguishes equal status accuracy from equal behavior.}
1272: We additionally code two action-specific behaviors descriptively on the same
1273: 36 cases. For the 16 NEEDS\_INFO cases, an action is counted as realized only
1274: when the response explicitly asks the user to provide or report further
1275: diagnostic information; structured generation does so in 16/16 cases, versus
1276: 4/16 raw-metadata responses. For the 7 REDIRECTED cases, an action is counted
1277: as realized only when the response explicitly routes the user away from the
1278: retrieved duplicate---for example, by saying the issue is tracked or addressed
1279: elsewhere or by directing the user to related tracker discussion. Merely
1280: stating that an issue is a duplicate does not count. Structured generation
1281: realizes this routing in 7/7 cases, versus 0/7 raw-metadata responses. This is
1282: a post-hoc descriptive mechanism audit, not a second confirmatory accuracy
1283: test, but it directly measures the operational effect that the action selector
1284: is designed to impose.
